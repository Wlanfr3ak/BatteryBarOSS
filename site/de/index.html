⭐ Fehler gefunden oder eine Idee? Issue auf GitHub eröffnen — die komplette Dokumentation liegt im Repository.

Windows SmartScreen: Die Binärdateien sind noch nicht code-signiert, daher kann beim ersten Start ein blauer „Windows protected your PC"-Dialog erscheinen — erwartet bei einer neuen unsignierten EXE, keine Malware. Weitere Informationen → Trotzdem ausführen klicken. Jede Release enthält SHA256SUMS.txt zur Integritätsprüfung (certutil -hashfile datei.exe SHA256). Echte Signierung über die SignPath Foundation ist geplant.

Eine Leiste, alles Wichtige

Echte Restlaufzeit-Schätzung

Fuel-Gauge-mWh/mW-Werte, lernender Sitzungsdurchschnitt und Countdown bis zur konfigurierbaren Reserve — plausibel Sekunden nach dem Unpluggen.

Akku-Gesundheit

Echte Design- vs. Vollladekapazität, Verschleiß-%, Ladezyklen und optionaler HP-BIOS-Akkumodus (BHM).

Null Abhängigkeiten

Zur Laufzeit nur Python-Standardbibliothek; das Release kommt als portable EXE oder Per-User-Installer — keine Adminrechte.

Deins zum Formen

Ziehen, Größe ändern, Click-through, Hotkeys, JSON-Themes und Formatstring-Anzeige — plus Self-Updates von GitHub Releases.
