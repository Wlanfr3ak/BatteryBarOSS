4. Client-side GitHub API call

When the landing page loads, your browser queries the GitHub API (api.github.com) to determine the latest release version and download links; your IP address is transmitted to GitHub in that request. Without JavaScript no API call is made (the static fallback links keep working).

5. Note on the software

BatteryBar OSS itself does not transmit data. Its optional update check calls api.github.com only after your consent (first-start dialog or manual menu entry) and only over HTTPS; declined or unanswered means it never checks.
